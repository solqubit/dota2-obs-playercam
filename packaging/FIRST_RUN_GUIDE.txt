OverPower Dota Player Cams  -  First-run guide
================================================

What it does: when you select a player in Dota 2 (spectator mode), the app
puts that player's scene on air in OBS (camera or photo, name and border) and
takes the previous one off. It works on its own; just keep it open.

You need: Windows 10/11, Dota 2 and OBS Studio 31.1 or later, the "Move
Transition" plugin for OBS (see step 4), and an OBS scene collection: the one
your event organizer sent you, or the example included in this .zip
(the Camaraman folder; full instructions in Camaraman\LEEME-DEMO.md).

Updating from v1? v2 uses a different OBS structure, so a v1 scene does not
work with it: import the example (step 5). Your v1 settings (OBS password,
Dota folder, language, side, learned portraits) are kept. Run the checks once
so the GSI file is updated to also send abilities.


1) INSTALL
   - Extract the WHOLE .zip (right click -> Extract All). Do not run the app
     from inside the zip and do not move the .exe out of its folder: it needs
     the files next to it.
   - Open "DotaPlayerCams.exe" inside the DotaPlayerCams folder.
   - Language: the app starts in your Windows language (Spanish or English).
     Change it in Settings -> Language; it stays fixed.

2) IF WINDOWS SAYS "WINDOWS PROTECTED YOUR PC" (SmartScreen)
   The app has no paid digital signature, so Windows does not recognize the
   publisher. It does not mean it is dangerous.
   - Click "More info", then "Run anyway". It only shows up the first time.

3) IF YOUR ANTIVIRUS BLOCKS OR DELETES IT
   The app listens to keys and clicks while Dota is the active window (that is
   how it switches cameras instantly), and some antivirus tools mistake that
   for spyware.
   - Windows Security -> Virus & threat protection -> Manage settings ->
     Exclusions -> Add or remove exclusions -> Add an exclusion -> Folder.
   - Choose the whole DotaPlayerCams folder and open the app again.
   - If it was deleted, restore it from the antivirus protection history,
     then add the exclusion.

4) INSTALL THE MOVE TRANSITION PLUGIN (required, installer included)
   - Close OBS, run Camaraman\Plugins\move-transition-3.2.1-windows-installer.exe,
     then restart OBS. This is Exeldro's original installer; its license and source
     are included too. The app does not install plugins automatically.
   - The app uses it to resize the player's scene when the player has 5 or 6
     abilities. Without it, scenes still switch but are not resized.

5) IMPORT THE SCENE INTO OBS
   - Run PREPARAR_DEMO.cmd and select the extracted Camaraman folder.
     This links all graphics without changing your current OBS collection.
   - In OBS: "Scene Collection" menu -> "Import". Add the scene .json file
     (Camaraman\Ecenas\Camaraman-lista.json) and confirm.
   - Then "Scene Collection" -> pick the imported collection (the example is
     called "Camaraman Demo").
   - Use a 3840x2160 base canvas. Output may be 1080p or QHD without changing filters.
     See Camaraman\LEEME-DEMO.md for base-canvas conversion details.
   - The collection has this structure (keep these names):
       "Juego": the Dota 2 capture, the 10 player scenes and "Borde".
       10 player scenes: "1 Hard carry", "1 Mid laner", "1 Offlaner",
       "1 Soft support", "1 Hard support", and the same with "2 ".
       4 sources inside each player scene: "Camara · <scene>",
       "Foto · <scene>", "Fondo · <scene>" and "Nombre · <scene>"
       (the separator is space, middle dot, space).
       3 Move Source filters in "Juego": "H 4 habilidades",
       "H 5 habilidades" and "H 6 habilidades". They hold the position and
       scale of the player's scene for 4, 5 and 6 abilities. Adjust them to
       your canvas (the example is built on 3840x2160).
   - "Borde" is fixed and is only visible while a player scene is on air.
   - If a collection has "Juego" but lacks player scenes, the app's "OBS
     scene" page can create them by copying "1 Hard carry" (it asks first).

6) TURN ON OBS WEBSOCKET AND ENTER THE PASSWORD
   - In OBS: Tools -> "WebSocket Server Settings" -> tick "Enable WebSocket
     server". Copy the password (or create one).
   - In the app: "Settings" page (left menu) -> paste it into "OBS
     WebSocket password" -> "Save". It is stored only on this PC.

7) FOLLOW THE CHECKS ON SCREEN
   On start, the app checks OBS, Dota, the scene and the hotkeys. On the left
   each item is green (good), yellow (warning) or red (missing), with
   instructions or a "Fix" button. The app never changes anything without
   asking, and Dota hotkeys are only fixed with Dota closed.
   Click "Re-check everything" after each fix until everything is green.
   Images (border, camera mask and name background): they come with the app
   in DotaPlayerCams\_internal\assets (Borde.png, Mascara camara.png and
   Marco sin camara.png). Click "Fix" and the app sets them in OBS.

8) FILL IN THE PLAYERS ("Players" page)
   For each of the 10 players: name, camera link (VDO.Ninja), photo link and
   Camera / Photo. Changes are saved and applied in OBS right away (name,
   links and Camera/Photo); if that player is on air, you see it at once.
   If the selected URL is empty, both media sources are hidden; the scene transform still applies.

9) DURING THE MATCH (bar at the top of the window)
   - "Radiant is": choose which team is Radiant after the coin toss.
   - "Mode": Automatic = the scene follows the player you select.
     "Hide all" = nothing on air (the app stops listening to keyboard and
     mouse).
   - Only one player scene is on at a time. "Test" in the "OBS scene" page
     plays each H filter so you can adjust it.
   Keep the window open while you stream.

Something not working? Look first at which item is red or yellow in the
Checks page; it almost always tells you what to do.
